## Как переснять

```bash
node scripts/capture-screenshots.mjs
```

Нужны: Node 24, pnpm, Docker (postgres), ffmpeg (сборка gif). Скрипт сам
достаточен: пересоздаёт выделенную базу `beautiful_todo_capture`, собирает оба
приложения в прод (web указывает на локальный api), регистрирует демо-аккаунт и
снимает все скриншоты полностраничными кадрами Playwright, а обе гифки — из
последовательностей кадров. В финале перегенерирует `og-image.jpg` по свежему
`desktop/todo.png`.

Съёмка не трогает dev- и e2e-базы.
